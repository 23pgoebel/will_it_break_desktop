# Will it Break?

Will it Break? is a Python desktop app for building and testing 2D bridge designs. It shows bridge cost and stability, and lets you test vehicle and validation loads while viewing member forces.

## Requirements

- Python 3.10 or newer with Tkinter/Tk.
- No additional `pip` packages are required. On Linux, install your distribution's Tkinter package (often `python3-tk`) if needed.

## Start

```bash
python app.py
```
